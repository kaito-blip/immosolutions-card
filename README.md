# Immo Solutions — Digitale Visitenkarte

Digitale Visitenkarte für **Gabriel Zekry**, Gründer von **Immo Solutions** (Basel) —
im Immo-Solutions-Branding (Fraunces-Serif, Blau #2b59ff, Rauten-Logo), als Klon der
KWI-Capital-Karte aufgebaut.

**Live:** https://kaito-blip.github.io/immosolutions-card/

## Inhalt
| Pfad | Inhalt |
|---|---|
| `index.html` | Die Karte — aufklappbar (Vorder-/Rückseite), 3D-Tilt, Aktions-Buttons |
| `gabriel-zekry.vcf` | Kontakt zum Speichern (Button „Kontakt speichern") |
| `assets/` | Logo (SVG), Apple-Touch-Icon, App-Icon |

## Nutzung
Link teilen oder als QR-Code drucken. Auf dem iPhone via Safari „Zum Home-Bildschirm
hinzufügen" für App-artigen Zugriff. Der Button **Kontakt speichern** lädt die vCard
direkt in die Kontakte.
